# **🎓 华南农业大学本科生毕业论文 LaTeX 模板 (2026版)**

本项目为华南农业大学本科生（理学、工学、农学）提供一个开箱即用的毕业论文 LaTeX 模板。

本模板按照《华南农业大学本科生毕业论文撰写规范》（2024修订版）编写（规范文档已附在项目中），已实现约 **95%** 的格式要求，剩余极少部分细节可根据自身具体情况微调。

## **📦 模板核心功能与排版规范说明**

本模板的导言区已经为您配置好了符合学校规范的各类底层参数。**除非有特殊需求，一般不建议修改标注了“非必要不修改”的核心参数。**

### **1\. 📄 页面与基础排版**

* **纸张与边距：** 采用 A4 纸张，单面打印。页边距经过物理直尺测算微调：**对应word的**上下左右各2.4cm，装订线 0.5cm。  
* **行距设置：** 基础行距参数固定为 1.70，这在视觉上等效于 Word 中的“1.5倍行距”。  
* **页眉页脚：** 全文无页眉。页脚仅包含居中的页码（五号字，两侧无修饰线）。  
* **默认字体：** 英文默认采用 Times New Roman。

### **2\. 📊 图、表与公式**

* **图表标题：** 统一采用五号宋体。表题自动置于表格上方，图题自动置于图片下方。图号/表号与标题文字之间自动空1个字距。  
* **分图支持：** 支持子图排版，子图编号自动格式化为 (a) (b) 并置于分图之下。  
* **三线表：** 默认配置好 booktabs 宏包，上下粗线设为 1.5 磅，中间细线设为 1 磅。  
* **公式编号：** 自动将公式编号格式化为 (式1)、(式2) 并靠右对齐。

### **3\. 📑 标题与目录格式**

* **多级标题：**  
  * 一级标题：黑体四号字，左顶格。  
  * 二级标题：黑体小四号字，左顶格。  
  * 三、四级标题：楷体小四号字，左顶格。  
  * *注：标题编号后自动空1个字距，且已处理好段前后间距缓冲。*  
* **目录自动化：** 自动生成至三级标题，目录标题“目 录”两字居中空4个字距（黑体四号），正文内容统一为宋体小四号。已修复长编号与汉字粘连的问题。

### **4\. 🔗 智能交叉引用与定理环境**

* **智能引用 (\\cref)：** 引入了 cleveref 宏包并完全汉化。文中引用时只需使用 \\cref{标签}，即可自动生成如“图1”、“表2”、“式3和式4”、“第1节”等带超链接的文字，无需手动输入“图”或“表”字。  
* **数学与定理环境：** 预置并定制了适合中文排版的定理环境（独立计数）。  
  * 包含：theorem (定理)、lemma (引理)、remark (注解)。  
  * 格式：首行自动缩进两字符，表头为黑体，正文强制不倾斜（宋体）。  
  * 证明环境：原 Proof 已汉化为黑体的“**证明**”。

### **5\. 📎 附录专项适配**

* **附录开关：** 提供了一键式 \\startappendix 命令。在正文结束后调用此命令，所有章节、图、表、公式的编号将自动切换为 A, B, C 序列（如：附录A、图A1、表B1、式C1）。

## **🚀 快速开始**

本项目提供两种使用方式，请根据自身需求选择。

### **方法一：本地部署（TeX Live \+ VS Code）【🌟 强烈推荐】**

**优势：** 上限高、配置灵活、无需联网、编译速度快。建议用电脑硬盘空间换取无痛的 Debug 体验。

1. **安装编辑器**：下载并安装 [Visual Studio Code](https://code.visualstudio.com/)。  
2. **安装插件**：在 VS Code 扩展商店中安装以下 LaTeX 插件：  
   * LaTeX Workshop (by James Yu)  
   * LaTeX Utilities (by tecosaur)  
3. **安装编译器**：前往 [TUG 官网](https://www.tug.org/texlive/) 下载并安装 **TeX Live**（强烈推荐“Full/全部”安装模式）。  
4. **获取项目**：下载本项目压缩包并解压，使用 VS Code 打开该文件夹。  
5. **检查文件**：确认当前目录下同时存在 SCAU-Thesis-Template-2026.tex 和 SCAU-LOGO.jpg。  
6. **准备编译**：在 VS Code 中打开 .tex 文件，点击左侧边栏底部的 **TeX** 图标。  
7. **执行编译**：  
   * 在 COMMANDS 栏下找到绿色的播放键（Build LaTeX project）。  
   * **注意**：不要直接点播放键，点击它左侧的 \> 展开细分选项。  
   * 找到并点击 Recipe: xelatex \-\> xelatex 进行自动编译。  
8. **日常使用**：后续只需修改代码并按下 Ctrl \+ S 保存，即可自动编译更新 PDF。如遇报错，请重试步骤 6-7。

### **方法二：在线使用（Overleaf）【☁️ 备选方案】**

**注意：** 需要全程联网，编译速度受网络影响较大。如果论文篇幅过长，可能会提示编译超时（需开通会员），因此**不作为首选推荐**。

1. 打开并登录 [Overleaf 官网](https://www.overleaf.com/)。  
2. 点击左上角绿色的 **New Project (新建项目)** \-\> 选择 **Blank Project (空白项目)** 并随意命名。  
3. **导入文件**：  
   * 在左侧文件栏删除默认生成的 main.tex。  
   * 上传本项目中的 SCAU-Thesis-Template-2026.tex 和 SCAU-LOGO.jpg。  
   * 确认左侧边栏中包含这两个文件。  
4. **更改编译器（非常重要）**：  
   * 点击左上角（Overleaf 叶子图标旁）的 **Menu (菜单)**。  
   * 在弹出的侧边栏中找到 **Settings (设置)** \-\> **Compiler (编译器)**。  
   * 将默认的 pdfLaTeX 更改为 **XeLaTeX**，关闭菜单。  
5. **编译生成**：点击右侧预览窗口上方的 **Recompile (重新编译)** 等待 PDF 生成。  
6. **下载成品**：若需下载 PDF，点击重新编译旁边的 Download PDF 按钮即可；若需下载 .tex 源文件，点击左侧边栏的三个点图标进行下载。
